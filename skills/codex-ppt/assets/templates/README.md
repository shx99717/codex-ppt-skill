# Bundled PPT templates

Two 3-page Medavis templates used by `scripts/assemble_ppt.py --template medavis|both`. Each file is landing (`<PPT-Title>`), blank content, then ending. Pick the file that matches `--aspect-ratio`:

- `medavis_ppt_template_2026_en_16-9.pptx` — 16:9
- `medavis_ppt_template_2026_en_4-3.pptx` — 4:3

`medavis-logo-small.png` is a separate overlay on content slides only (top-right, 10px equal margin). Do not use `medavis-logo-original.png`.

Treat these binaries as skill assets — do not edit casually; replace only when intentionally updating the official template.
