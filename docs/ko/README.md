# Codex PPT Skill 문서

Codex PPT는 Codex용 PPT 생성 skill이며, Claude Code, OpenClaw, Hermes Agent 등 `SKILL.md`를 지원하는 agent에서도 사용할 수 있습니다. 글, 보고서, 논문, 수업 노트 또는 거친 아이디어를 이미지형 프레젠테이션으로 변환합니다. 먼저 개요와 시각 스타일을 설계하고, 각 슬라이드의 완성 이미지를 차례로 생성한 뒤, 마지막으로 `.pptx` 파일로 조립합니다. 주제부터 완성된 페이지별 Markdown까지, 준비 상태가 다른 혼합 입력으로 시작할 수 있습니다. 완성 문구·대본을 재사용하고 중요한 빈틈만 확인하며 비용이 큰 이미지 생성 전에 정확한 내용, 시각적 의미와 자연스러운 대본을 함께 승인합니다. 기본은 현재 이미지 통합 검토이며 배치별 검토도 가능합니다. 작은 래스터 차이는 생길 수 있습니다.

## 문서 읽는 순서

빠르게 시작하려면 먼저 [빠른 시작](/ko/quickstart.md)을 읽으세요.

설치, 모델 설정 또는 여러 agent 연동 방법이 필요하다면 [설치 및 설정](/ko/installation.md)을 읽으세요.

전체 생성 과정, 확인 단계와 품질 관리를 이해하려면 [표준 워크플로](/ko/workflow.md)를 읽으세요.

사용 중 문제가 생겼다면 [자주 묻는 질문](/ko/faq.md)을 확인하세요.

## 주요 기능

- 이미지형 PPT 생성: 각 페이지가 잠긴 비율(16:9 / 4:3)의 완성된 슬라이드 이미지로 만들어져, 강한 시각적 표현과 일관된 스타일이 필요한 상황에 적합합니다.
- 단계별 확인 절차: 개요, 시각 스타일, PPT 비율, 이미지 생성 방식과 샘플 슬라이드를 먼저 확인한 뒤 전체 PPT를 생성해 재작업을 줄입니다.
- 12가지 내장 스타일: 손그림 기술 설명, 연구 발표, 깔끔한 전문 스타일, McKinsey 스타일, 당·정 홍보용 레드 스타일, 교육용 코스웨어 등 다양한 방향을 제공합니다. 자세한 내용은 [스타일 및 개인 스타일 라이브러리](/ko/styles.md)를 참고하세요.
- 참고 자료 기반 스타일 재현: 사용자가 제공한 PPT, PDF 또는 스크린샷을 읽고 각 페이지의 이미지 스타일을 이해한 뒤 유사하게 생성할 수 있습니다.
- 개인 스타일 라이브러리 축적: 마음에 드는 스타일을 `~/.codex-ppt-skill/references/`에 저장할 수 있습니다. skill 설치 디렉터리 외부에 보관되므로 skill을 업데이트해도 사라지지 않으며, 이후 이름으로 바로 재사용할 수 있습니다.
- 지정 이미지 삽입: 논문 원본 이미지, 실험 결과 그래프, 아키텍처 다이어그램 또는 스크린샷을 특정 슬라이드에 사용하도록 지정할 수 있습니다.
- 여러 agent 환경 지원: Codex 외에도 Claude Code, OpenClaw, Hermes Agent 등 `SKILL.md`를 지원하는 agent에서 사용할 수 있습니다.
- PowerPoint 자동 조립: `outline.md`, 각 슬라이드 이미지, `speech.md`를 생성하고 최종적으로 `.pptx` 파일로 조립합니다.
- 서드파티 API를 통한 텍스트 모델 및 설정된 이미지 모델 이미지 생성 모델 사용 지원.
- PPT 발표 대본 생성을 지원하며, 기본적으로 PPT 메모 영역에 자동 삽입합니다.
- 생성 후 만족스럽지 않은 특정 슬라이드만 선택적으로 수정할 수 있습니다. 자세한 내용은 [자주 묻는 질문](/ko/faq.md)을 참고하세요.

## 활용 사례

- 기술 문서를 발표용 PPT로 변환
- 논문, 연구 보고서 또는 조사 자료를 프레젠테이션으로 변환
- 수업 노트를 강의 자료로 변환
- 제품 소개, 비즈니스 보고, 프로젝트 회고
- 연구 발표, 프로젝트 신청, 중간 점검, 최종 검수
- 일관된 시각 언어가 필요한 이미지형 프레젠테이션

## 중요 안내

Codex PPT는 이미지형 PPT를 생성합니다. 시각적 일관성은 높지만, 슬라이드 안의 텍스트, 차트와 도형을 기존 PPT처럼 개별적으로 편집할 수는 없습니다.

편집 가능한 PPT로 추가 변환해야 한다면 생성 후 [image-to-editable-ppt-skill](https://github.com/shx99717/image-to-editable-ppt-skill)을 사용할 수 있습니다.

현재 호출 가능한 Codex `image_gen` 또는 Cursor `GenerateImage`를 우선하며 실제 도구 schema를 확인합니다. 네이티브 모델은 호스트가 관리합니다. Codex는 size 인자 없이 프롬프트로 16:9 또는 4:3을 요청할 수 있고, Cursor는 지원되는 `aspect_ratio` 값을 전달합니다. 저장 파일의 실제 가로/세로를 측정하고 2% 비율 허용 오차를 검사합니다. 해상도 요청은 네이티브 4K의 증거가 아닙니다. API 대체 경로는 명시적으로 설정한 공급자 모델을 재사용하고, 없으면 최신 공식 문서에 따라 선택합니다. 고정 기본 모델은 없습니다. 실제 입력 방식으로 모든 원본/스타일 이미지를 첨부하고 현재 시도에 연결된 제출 증거를 기록합니다. 네이티브/브리지 증거는 에이전트 보고이며 CLI 검증에는 등록된 성공 실행이 필요합니다. 과거 파일은 읽을 수 있지만 새로운 관리 실행/조립에는 재컴파일과 새로운 증거가 필요합니다. 덱은 16:9와 4:3만 지원하며 이전 비율을 자동 변환하지 않습니다.

대본은 이미지 생성 전에 발표 언어로 작성하며 발표자의 따뜻한 일상 말투를 사용합니다. 구체적인 장면, 빈 줄로 나눈 생각 단위, 자연스러운 연결과 목적 있는 전환을 담습니다. 제공한 대본은 보존하고 실질적인 추가 내용은 승인받습니다. 길이는 발표 시간과 복잡도에 맞춥니다.

관리 v2 스크립트는 현재 내용·대본·정책 결정, 원본·샘플 바이트, 컴파일 입력, QA와 현재 이미지의 실제 사용자 승인을 검사합니다. 이전 수동·이미지 전용 작업은 `--legacy-unmanaged`를 명시해야 하며 관리 승인을 우회할 수 없습니다. CLI 작업은 `run_slide_job.py`로 승인한 설정과 모든 이미지를 정확히 전달합니다.
